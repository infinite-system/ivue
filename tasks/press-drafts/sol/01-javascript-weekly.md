Subject: The class is the Options API with the pretending removed

Peter — JavaScript Weekly gives language ideas room when a package is only the proof.

ivue is a 1.1 kB class layer over Vue's reactivity. It turns plain TypeScript classes into reactive models while instances remain plain objects.

The reader's win is anatomy without a component DSL: state is a ref-returning getter, derivation is a plain getter, and action is a method. The underlying reduction is that Vue's tracked read already derives; `computed()` is a cache, not the default unit of thought.

Creation measured 55–253× faster than the compared model layers with every instance retained. The engine has 100% test coverage.
