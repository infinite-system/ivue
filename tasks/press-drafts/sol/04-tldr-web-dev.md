Submission title: Plain Vue classes, 1.1 kB, 55–253× creation

Submission text:

TLDR Dev readers get the claim in one pass: Vue's Options API promised code anatomy, while the Composition API supplied the machinery.

ivue is a 1.1 kB class layer over Vue's reactivity. It joins those two wins in plain TypeScript classes: ref-returning getters hold state, plain getters derive, and methods remain methods.

Retained-instance creation measured 55–253× faster than the compared model layers. The package has zero dependencies and 100% test coverage.
