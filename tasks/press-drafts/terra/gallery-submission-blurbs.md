## Godly

ivue.dev documents ivue, a 1.1 kB class layer over Vue's reactivity. Built with VitePress, the dark-first site pairs a typographic product story with live browser benchmarks: 1,000,000 instances in 22 ms and a 20,000,000-cell demo. The documentation is the demo surface.

## Dark Mode Design

ivue.dev is a dark-first VitePress documentation site for ivue, a 1.1 kB class layer over Vue's reactivity. Large type, measured claims, and interactive benchmarks share one system: visitors can run the engine measurements in their browser instead of taking a screenshot as proof.

## siteInspire

ivue.dev presents ivue, a 1.1 kB class layer over Vue's reactivity, through a VitePress documentation and blog system. The site turns technical receipts into the interface: live benchmarks, 20,000,000-cell experiments, source-linked articles, and a dark-first reading surface.
